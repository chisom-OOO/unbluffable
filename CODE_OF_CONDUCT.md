# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the work, not the person. Harassment of any kind isn't accepted.

To report a problem, open a private report via the repository's **Security → Report a vulnerability** form (it reaches the maintainer only), or contact the maintainer through GitHub. Reports are handled confidentially.
